# Random-game-python
Interactive Python terminal-based number guessing game with levels, coin economy, hint system, and developer mode. 🎮
# 🎯 Random Number Guessing Game (Python)

Ushbu loyiha Python dasturlash tilida yozilgan interaktiv terminal oʻyini boʻlib, unda oʻyinchi turli bosqichlarda kompyuter oʻylagan sonni topishi kerak. Oʻyinda oʻziga xos iqtisodiy tizim (coins), yordam doʻkoni (shop) va maxsus devmode mavjud! 🎮

## 🌟 Asosiy Xususiyatlari

- **5 ta Dinamik Bosqich (Levels):** Har bir bosqichda sonlar diapazoni va qiyinchilik darajasi oshib boradi.
- **Coin & Shop Tizimi:** Har bir toʻgʻri javob uchun coin beriladi. Coinlar evaziga yordam va qoʻshimcha urinishlar sotib olish mumkin.
- **Developer Mode:** Dasturchilar va test qiluvchilar uchun maxsus secret code.
- **Input Validation:** Notoʻgʻri kiritilgan maʼlumotlar va chegaradan tashqari sonlarni ushlab qoluvchi mantiq.

---

## 🛒 Doʻkon va Maxsus Kodlar

Oʻyin davomida quyidagi kodlardan foydalanishingiz mumkin:

- **`777`** — Yordam kodi (50 coin evaziga yashirin son **JUFT** yoki **TOQ** ekanligini aytadi).
- **`999`** — Urinish sotib olish (50 coin evaziga +2 ta qoʻshimcha urinish beradi).
- **`4566`** — Developer Mode (Cheksiz coin, cheksiz urinishlar va yashirin sonni koʻrish).
